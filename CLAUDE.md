# CLAUDE.md

Zie `AGENTS.md`.

Deze repo is `kantelbeer-site`: de merksite en dealercatalogus voor Kantelbeer, een fictieve B2B-klant van Raderwerk. `AGENTS.md` is leidend voor scope, Definition of Done, PR-conventies en verboden handelingen; die instructies gelden onverkort ook voor Claude.

Kort samengevat:

- Werk alleen binnen de scope van het gekoppelde Linear-issue.
- Draai `npm run typecheck` en `npm run build` vóór je een PR opent.
- Nooit mergen, nooit force-pushen naar `main`, nooit deployen buiten de preview, nooit geheimen toevoegen.
- Elke publieke pagina behoudt de voettekst: *"Demonstratiebedrijf van Raderwerk. Dit bedrijf bestaat niet."*
